# Quantum approach

The research question is whether structured quantum search could reduce candidate-search complexity for exactly-k outage sets. The planned formulation maps valid outage combinations to an oracle and objective value. Grover-style search is a Tier A/B formulation or classical emulation; Dürr–Høyer is a minimum-finding formulation; QAOA is an exploratory optimization formulation.

Resource estimates must include qubits, oracle ancillas, depth, repetitions, data loading, verification, and error correction assumptions. They are ESTIMATED, not observed speedups. Tier C hardware execution requires circuits, backend, calibration, shots, noise model, and raw results. No quantum provider, hardware run, or advantage is implemented here.
