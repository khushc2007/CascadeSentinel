# Claims and evidence

| Claim type | Minimum evidence | Scaffold status |
|---|---|---|
| API availability | Reproducible health request | IMPLEMENTED |
| Deterministic cascade | Unit tests, fixed case, trace replay | NOT IMPLEMENTED |
| Grid fidelity | Authorised case, AC cross-check, validation report | NOT IMPLEMENTED |
| Classical scaling | E7–E9 manifests and repeated measurements | NOT IMPLEMENTED |
| Quantum search behavior | E10–E13 circuits or audited emulation | NOT IMPLEMENTED |
| Quantum resource crossover | E14–E16 assumptions and sensitivity analysis | NOT IMPLEMENTED |

Evidence labels are mandatory: IMPLEMENTED, DESIGN-STAGE, PROPOSED, EMULATED, ESTIMATED, or NOT IMPLEMENTED. The repository must not promote a model assumption, toy output, or analytical estimate to a measured result.
