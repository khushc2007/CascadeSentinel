# Experiments

E0–E16 are the frozen experiment sequence: E0 environment/provenance, E1 case validation, E2 base case, E3 single-outage checks, E4 exactly-k enumeration, E5 cascade determinism, E6 severity calibration, E7 exhaustive search, E8 classical ranking, E9 scaling, E10 oracle encoding, E11 Grover emulation, E12 Dürr–Høyer emulation, E13 QAOA formulation, E14 resource estimation, E15 noise/hardware sensitivity, and E16 crossover/evidence audit.

Each run must have a manifest, immutable inputs, configuration, seed, software revision, logs, and machine-readable results. A failed or incomplete experiment is recorded as such; missing data is never replaced with invented measurements. This scaffold contains no completed E0–E16 results.
